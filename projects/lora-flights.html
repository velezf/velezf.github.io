Every record the Apogee LoRa ground station logs — link quality, packet loss, and full altitude/RSSI/G-force traces straight from the flight logs. The genesis entry is a bench validation of the whole RF chain, not a launch.
Published

July 8, 2026

Companion to the LoRa RadioRocket build. Each flight the ground station records is derived into a small flights.json summary plus a per-flight CSV of the raw 1 Hz packets; this page reads those directly. Altitude is shown AGL — height above the launch pad — computed as raw barometric altitude minus a stability-gated pad baseline that locks the instant launch is detected. The baseline and the window it used are printed with every flight, so any AGL number here can be re-derived.

Note

Genesis entry (2026-07-08-F1) is a bench “shake test,” not a launch. A hand-swung sled tripped launch detection (>3 g), so the state machine and the whole pipeline ran end to end — but the ~10 ft “peak AGL” is barometric sensor noise, not a climb. It’s here honestly, as the first real over-the-air record.

trace = d3.csv(sel.csv, d3.autoType)
Code 
// T+ from received_at, not MET: MET is whole seconds on the wire, so at the
// 10 Hz flight rate ten packets share a value and an x: "MET" trace renders
// as vertical stacks. received_at carries milliseconds; t0 is the flight's
// t_start, so T+ starts at 0 for every flight, old 1 Hz records included.
tplus = d => (+d.received_at - +new Date(sel.t_start)) / 1000
Code 
// Focus the x-axis on the FLIGHT: the derived window includes the landed
// recovery beacon (minutes of flat line after a ~40 s flight), which squeezed
// the interesting part into the left edge. tEnd = last moment above 25 ft AGL
// + 15 s of landing context; a record that never clears 25 ft (the bench
// genesis entry) keeps its full span.
tEnd = {
  const ts = trace.map(d => [tplus(d), d.ALT - sel.baseline_ft]);
  const aloft = ts.filter(([t, h]) => h > 25);
  const full = d3.max(ts, d => d[0]);
  return aloft.length ? Math.min(d3.max(aloft, d => d[0]) + 15, full) : full;
}

Companion to the [LoRa RadioRocket](lora-radiorocket.qmd) build. Each flight the ground
station records is derived into a small [flights.json](lora-flights/flights.json) summary
plus a per-flight CSV of the raw 1 Hz packets; this page reads those directly. **Altitude is
shown AGL** — height above the launch pad — computed as raw barometric altitude minus a
stability-gated pad baseline that locks the instant launch is detected. The baseline and the
window it used are printed with every flight, so any AGL number here can be re-derived.

::: {.callout-note}
**Genesis entry (2026-07-08-F1) is a bench "shake test," not a launch.** A hand-swung sled
tripped launch detection (>3 g), so the state machine and the whole pipeline ran end to end —
but the ~10 ft "peak AGL" is barometric sensor noise, not a climb. It's here honestly, as the
first real over-the-air record.
:::

```{python}
# | echo: false
import json
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

sns.set_theme(style="whitegrid", context="talk")
flights = pd.DataFrame(json.load(open("lora-flights/flights.json")))
flights["date"] = pd.to_datetime(flights["date"])
```

## Link quality

```{python}
# | echo: false
# | fig-cap: "Packet loss per record — received vs dropped by sequence number. The genesis entry ran 75 packets with a single drop (1.32%) at RSSI −38…−14 dBm: the RF chain, decoder, and logger working end to end."
fig, ax = plt.subplots(figsize=(9, 3.5))
sns.barplot(data=flights, x="flight_id", y="loss_pct", color="#dd6b20", ax=ax)
ax.set_ylabel("Packet loss (%)")
ax.set_xlabel("")
plt.tight_layout()
```

## Peak AGL over time

```{python}
# | echo: false
# | fig-cap: "Peak altitude above ground, per record. One entry so far, and it is a hand-swing artifact (~10 ft of barometric noise) rather than a climb — the axis will mean something after the first real launch."
fig, ax = plt.subplots(figsize=(9, 3.5))
ax.scatter(flights["date"], flights["peak_agl_ft"], s=90, color="#2b6cb0", zorder=3)
ax.set_ylabel("Peak AGL (ft)")
ax.set_xlabel("")
ax.margins(x=0.3)
plt.tight_layout()
```
